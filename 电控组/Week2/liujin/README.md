## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic |发布/订阅 多个对多个|单向持续的发，不管听没听到有没有回应|持续发布球的位置 持续广播速度指令发布战术|
| 服务 Service |一对一 有回应 请求/响应|有说有回答 双方同步，调动一次回答一次|切换对战的模式如进攻防守 询问比分|
| 动作 Action |事情的结果/反馈|是一个长的过程，在进行中可以反馈并中途停止|机器人在运动过程中汇报自己的位置，随着情况变化可以取消动作|

**我实际用到的服务调用**：比如任务 2 开始前的 `ros2 service call /clear std_srvs/srv/Empty`，这是服务，因为在输入后是有一个清屏动作的回应，而且只有这一次，并不是持续的

## 四、差速三公式

- `v = (vL + vR) / 2` → 左轮和右轮的平均速度
- `ω = (vR − vL) / L` → R1=vR/角速度 R2=vL/角速度 L=R1-R2推出该公式，当右轮速度大时为正数，车向左转
- `r = v / ω` → 高中学的物理公式
